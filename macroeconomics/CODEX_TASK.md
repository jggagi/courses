# Codex task｜实现宏观经济学 Phase 1

**目标：只在 `macroeconomics/` 内实现一套可实际学习的中文宏观课程首期：先理解对象、核算与测量，再扩展政策模型。** 这是实施任务，不是让你再次输出课程规划。不要做没有计算内核的经济仪表盘。

## 0. 开始和范围

先读根目录 `AGENTS.md`、`LEARNING_DESIGN.md`，再读本目录全部6份设计文档。检查现有实现与Git状态；已有内容只增量改进，不覆盖未提交改动。建议工作分支 `codex/macroeconomics-phase1`。所有依赖、代码、测试和文档更新只在本课程目录；不得修改微观课程或根文件。

**必须完成：** A01–A03共6节可读可练课程、LA01–LA03共3个真实实验、24节完整规划目录、局部概念导航、来源/数据标注、练习反馈、模型卡、笔记与本地恢复状态。

**不做：** A04–A12的完整正文和模型、实时经济数据、政策/市场预测、LLM导师或判卷、银行/投资账户接入、账号后台、云同步、共享课程引擎、部署。后续章节标“规划中”，不得冒充已完成。

## 1. 应用与目录

在本目录 `app/` 建独立Web应用。建议Vite + React + TypeScript；二维图、账表与流向用SVG/HTML，公式可用KaTeX。不需要3D、复杂图形引擎或数据库。实现时核验依赖官方文档，采用相容稳定版本并提交锁文件，不猜版本。测试可用Vitest和Playwright；已有合适工具则沿用。

```text
macroeconomics/
  app/

    src/
      content/          # lessons, terms, questions, sources
```

独立安装、启动、测试和构建；默认开发端口5174，与微观错开，冲突明确报告。提供hash路由与适合子路径的资源base，深链接刷新有效。不在根目录加工作区、依赖或CI；不运行另一门应用才让本课可用。首期无运行时第三方CDN、字体、分析SDK或外部数据请求。

## 2. 教学内容合同

稳定courseId为`macroeconomics`，课ID `A01-A` 至 `A12-B`。使用轻量本地类型，lesson至少有id、moduleId、centralQuestion、prerequisites、sections、definitions、modelTypeTags、assumptions、workedExample、labId、checks、counterexample、recap、references、status。

每节根据 `LESSONS_PHASE1.md` 形成完整中文讲解。定义与恒等式用标签和说明表达，不能只靠颜色；每个公式前先介绍对象/单位，之后解释它不能回答什么问题。6节每节至少3道检查（解释、数值、迁移/反例），选择题有干扰项反馈，数值题有容差和单位，自由回答给自评rubric，不使用关键词自动评分。

首期词条至少覆盖：主体、存量、流量、收入、财富、资产、负债、净值、储蓄、投资、消费、转移、准备金、存款、GDP、增加值、中间/最终使用、存货、名义/实际、价格指数、通胀/通胀放缓/通缩、同比/环比、百分比/百分点、恒等式/行为机制。

来源词条保留本地reference IDs与官方外链。数据面板常显“教学合成数据”，用第0/1/2期；不能添加未经查证的当前GDP、利率、通胀或现实国家标签。

## 3. 三个必须工作的实验

**LA01**：事件驱动账本。明确初始状态、已建模部门和外部准备金发行方边界。原始事件带唯一ID和顺序，reducer纯函数计算H/F/B账表、收入/支出与净值。工资、服务购买、本金偿还各有不同科目规则；每步校验平衡和双边一致。重复事件不能重复应用；撤销通过事件重放。不能用自动“其他资产/负债”行强行平衡错误。

**LA02**：生产活动与最终使用。按LABS的活动记录派生生产/支出/收入三侧；展示中間投入消除、存货、进口、新机器、转移、旧资产与前期库存。分类由用户先判断后揭示。收入与生产相等要来自明确科目和假设，不把所有销售额称GDP。每个结果可点回来源活动。

**LA03**：以原始p/q表为唯一源，计算N/R/D/L和增长率。编辑、三个预设、A/B比较、图表替代表与归一化切换均真实联动。0分母显示未定义；换指数刻度与改聚合权重分开。图轴注明单位，不能用同一曲线名称混淆名义和实际。

所有模型先写纯函数与oracle测试再做UI。预测可保存，也可显式跳过；运行结果后记录解释。A/B基准不可被B操作污染。重置实验不清空学习记录。

## 4. 状态和隐私

本地存储命名空间 `courses:macroeconomics:v1`。保存schemaVersion、courseId、lastLessonId、lessonStates、objectiveAttempts、selfChecks、notes、labStates和updatedAt。LA01保留初始状态/事件；LA02保留活动选择；LA03保留p/q、时期与归一化参数；不要只存无法复算的图坐标或截断小数。

刷新/关闭后恢复。校验结构和版本，损坏数据有明确恢复提示，不白屏、不自动覆盖原记录。localStorage不可用时内存回退并提示未持久保存。进度状态与根设计一致，阅读不等于掌握。

支持显式JSON导出/导入，校验courseId、schema、大小、事件类型、金额范围、数值有限性；拒绝微观文件和非法事件。导入数据仍经过模型验证，不能绕过余额检查。用户笔记按纯文本渲染。清空本课需确认，不能删除另一门课key；导出提示含私人笔记、不应提交公开仓库。

没有后端、自动上传、遥测、LLM调用或外链预取。参考网页由用户点击打开。不要为了未来AI导师预留带网络权限的空服务。

## 5. 必须实际执行的验证

**单元测试：**
- LA01：默认三步oracle、逐步资产=负债+净值、贷款/存款双边匹配；工资/消费不改总存款，本金偿还减少存款；重放/撤销；超余额、负金额、非有限数和重复事件处理。
- LA02：基础GDP100和全部指定场景；三法一致；存货重复计入、进口遗漏冲销、股票误算I等反例；前期存货销售C+20/I−20；期初库存下限；若源记录不平衡应明确报错。
- LA03：三期N/R/D/L oracle、增长乘法关系、价格/数量单独变动、指数归一化不改通胀、零分母、非法数据；不得错误测试“更换实际价格权重永远不改实际增长”。
- 内容：6个learnable课ID、18个planned课ID；全部有定义/来源/例题/反例/检查/反馈，无悬空词条、lab或reference。
- 状态：刷新、JSON往返、损坏/未知版本、微观文件拒绝、本课重置隔离、用户输入不执行脚本。

**真实浏览器E2E：**
1. 从首页进入A01-A，完成一次预测和自评；LA01按20/10/5事件执行，得到H110、F25/15、B存款135/权益40；撤销后恢复正确。
2. LA02从基础100切存货、进口、新机器，图表与三法结果保持一致；旧股票与转移解释正确。
3. LA03显示40→61→62.22的名义值及40→44→44实际值；第2期通胀2%而指数仍高于基准；非法值显示可理解错误而非NaN。
4. 保存笔记、预测和事件，刷新和深链接恢复；导出/清空/导入往返；混入另一门课文件被拒绝。
5. 全键盘操作、390px手机布局、约1440px桌面布局；宽账表提供适当滚动容器或堆叠视图，页面正文不整体溢出；图提供文字/表格替代，减少动画偏好生效。

必须运行安装、类型检查、单元测试、内容检查、生产构建及浏览器E2E。记录真实结果，至少保存并查看桌面、手机和一个边界/错误态截图；不得把“写了测试”写成“测试通过”。
