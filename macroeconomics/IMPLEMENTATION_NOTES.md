# 宏观课程实现说明

前半记录首期A01–A03/LA01–LA03的实现；后半记录用户后续授权的完整课程扩展。当前A01–A12与LA01–LA09全部实现，具体测试与发布版本见DELIVERY.md。原六节教学种子与三个实验的设计oracle相符，未修改设计中的数学结论。

## 计算与表示

- LA01 输入以教学货币单位表示，最多两位小数；内部转为整数最小单位计算。显示舍入不参与后续计算。交易 ID 唯一且顺序严格递增，撤销通过从期初重放剩余事件。工资与消费分别进入收入/费用与净值，本金偿还只减少存款和贷款双方，不减少银行权益。
- LA02 用固定教学生产链及明确的工资/毛盈余科目生成三侧表，金额同样转为整数最小单位汇总，避免大额进口与小数存货抵消时的浮点误差。生产源记录须符合 30→50→100 的供给链；矛盾数据直接报错。未售与出口从本期成品的最终去向派生；进口消费同时增加 C/M；前期存货销售同时增加 C、减少 I；机器新增明确生产和收入科目。没有不明调整项。
- LA03 原始 p/q 是唯一计算源。固定实际价格权重与固定消费篮子时期分别选择；100/1000 刻度只改变指数表示。真正改变价格权重可能改变实际增长。无定义的指数或增长率用 `null` 表示，界面显示“未定义”。

## 审查中补强的实现边界

1. 正交易金额转换为整数最小单位后仍须大于零；`1e-9` 等不足最小单位的输入不能成为零金额事件。
2. 三侧总额一致不能代替供给链一致。上游产出 40、成品产出 90 即使凑出增加值 100，也不能配上固定成品最终使用 100；源活动校验拒绝这类记录。
3. 数据校验与 JSON 导入复用计算内核。损坏记录或未知版本不会被页面自动覆盖；只能由用户显式放弃或导入有效文件替换。
4. 极小但正的价格可能导致指数比率超出有限数值范围；模型对派生结果校验并给出范围错误，不把上溢混成“未定义”或显示 `Infinity`。

这些是对实现的修正与保护，并非更改课程设计。对应模型和状态测试保留可复现反例。

## 依赖与运行边界

独立 Vite / React / TypeScript 应用，hash 路由、相对资源 base、严格端口 5174。依赖版本通过 npm registry 核验并锁定；核验了 Vite、React、Playwright 的官方仓库说明和 Vite/测试工具的 Node engines 与 React 插件 peerDependencies。运行时不加载第三方字体、CDN、教材、真实数据或分析 SDK。

准备金发行方不在 LA01 展开的部门内；LA02 不模拟行为或政策响应；LA03 不复制官方 CPI 的链式、替代或质量调整。自由题只提供参考与 rubric，由学习者自评。


## 后续完整课程扩展的模型解释（2026-10-03）

用户后续明确要求完成全部设计。本节记录新增实验的精确边界，未修改根教学规则。

### LA04：正稳态、零初始资本与技术趋势

固定A的k*=[sA/(n+δ)]^(1/(1−α))是正资本路径的稳态基准；当k0=0且无外部启动资本时，k一直为0，不能声称任意初始状态都趋向正稳态。一次技术水平冲击可用冲击后的A求稳态；持续技术增长时A_t变动，不输出固定A稳态。总K/L递推与每工人方程逐步互证，储蓄率提高不自动代表更高福利。

### LA05：实现后核算与库存可行性

固定价格动态中的未计划存货变化为Y−Z，实际I=I0+Y−Z；从C+I0+G=Z得到C+实际I+G=Y，每一期恒等式成立。默认Y0=100时C=20+.6(100−20)=68、Z128、库存−28、实际I2；η=.5时下一期Y114。低Y0可出现负实际I，不能裁成0。实验没有期初库存存量与不可负约束，这些负流量的现实可行性需要可售库存，界面已明确警告。

### LA06：时序与稳定性

x_t先使用i_(t−1)、πe_(t−1)，之后更新π_t、πe_t，最后定i_t；同一期政策不能倒灌回缺口方程。表中的i_t−πe_t标为“当期事前实际利率”，不是用于x_t的过去实际利率。线性无下限部分的谱半径只给局部稳定性判断；下限可能改变路径，过大轨迹或数值溢出显示不稳定/有限前缀，不假造收敛值。

### LA07：银行减值、合同债务与支付

设计的“确认另一历史贷款损失8”解释为银行对该合同债权减值：净账面贷款72+显式损失准备8=客户合同本金80，银行权益减少8，但客户债务不自动免除，存款不随减值注销。这避免把银行会计减值冒称法律债务豁免。跨行付款假定用于当期使用或转移、不取得另一资产，因此付款方净值−7、收款方+7；如果购买资本资产，必须另写资产科目，现模型不模拟该分支。初始与每笔事件都检查客户/银行对应账、准备金与净贷款—合同额桥接。导入的严格递增顺序可以有间隔，UI下一顺序取最后序号+1，重放撤销保持一致。

### LA08/LA09：分母与符号不能简化掉

pd=初级赤字/当期GDP，而利息按期初债务；B_t=(1+i)B_(t−1)+pd·Y_t与精确债务率方程一致。净负债为负时显式标为政府净资产，不称负的毛债务；不据r/g判国家安全。开放核算保持原始Y=C+I+G+X−M，CA=NX+NPI+NCT=S−I；CA与估值分别桥接净外部资产。e为本币/外币，q=eP*/P，反向约定显示倒数但不改变经济结论；汇率不自动重写贸易量。

### 本地兼容与终课作品

同命名空间/schema1下仅迁移完整旧六课/三实验结构，其他混合或缺字段输入拒绝并保护原记录。新版A/B都经过纯内核复算；600项文字字典与1MiB总上限兼容全课笔记。终课默认参数及敏感性结果复用prices/growth/spending/policy/credit内核，模型分别对照，不把表中不同单位加成一个总指标；银行损失按整数分舍入。自由报告和自评以纯文本/显式勾选存储，无AI打分。
