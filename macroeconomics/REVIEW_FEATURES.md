# 本地复习工作台

新增路由由应用入口接入 `#/review`；`src/components/Review.tsx` 默认导出 `Review({ state, change })`，并自行导入专属样式。课程正文完整导入仅用于该复习组件，入口可把组件作为异步分块。

错题按每道题的最新追加记录建立清单，重新用当前数值答案、容差或选项反馈核对原始回答，**不信任导入文件的 `correct` 标记**。新的正确重做移出清单，原错误仍留在尝试历史；未知旧题、课题归属不一致和误存为客观题的自由回答单独显示为无法核实，不能算作正确或错误。时间戳只展示，不重排追加顺序。页面展示近10次题目历史与近20条无法归入的记录，JSON保持课程原有记录范围；新提交沿用原应用最近1000条的上限。

回原题链接格式 `#/lesson/<lessonId>/check/<checkId>`，入口应识别并聚焦 `id="check-<checkId>"` 的题目。回模型卡格式 `#/lesson/<moduleId>-B/card`，入口应聚焦 `id="card-<moduleId>"` 的模型卡。

六道原创跨模块迁移题覆盖A01–A12，分别连接账本与生产、价格与资本、技术与需求、劳动口径与政策滞后、公共债务与外部核算、银行风险与因果证据。数字由课程现有纯计算内核生成，配参考解释与三项自评标准；自由回答没有自动评分。12模块的模型卡复用原有七字段 `card:<module>:<字段>`，已填字段数只提示哪里有文字。

沿用 `schemaVersion:1`，不增加顶层状态字段，不更改导入验证合同；本地复习笔记和显式自评保存在 `notes` / `selfChecks` 的 `review:` 键下。迁移回答、误解解释或模型卡被改写时，取消针对旧文字的自评。原课模型卡修改时，入口也应取消 `selfChecks[review:card:<module>]`。复习重做同步原 `response:<checkId>` 答案，追加同一客观题历史，并保留完成本课自由回答自评后的 `self_checked` 状态。
