# 微观经济学实现说明

下文按 Phase 1、完整课程、学习工具的实现顺序记录。当前合同为24节/14实验/schema3；前期状态描述保留为历史背景。

## 数学内核与教学参数

`app/src/models/economics.ts` 为无 UI、状态、网络依赖的纯函数。货币预算 m 与价格使用同一个计价单位；x、y 是相应商品数量。数学有效域是 m≥0、px>0、py>0，所有输入须有限；CD 要求 0<α<1，线性权重 a,b>0，互补固定 1:1。实验控件仍应按 LABS.md 限制各自的教学范围：ML01 的 m≤300，ML03 的 m≤200，价格 1–20，CD α=.1–.9；数学内核的宽域允许不改变实际可行集的计价单位变换。非法输入抛出可解释的 RangeError，不作静默裁剪。

预算线为 y=m/py−(px/py)x；预算集合包含边界与内部。零预算特判为只有原点，极小正数量也不能因显示容差变为可行。支出与理论相等关系只使用浮点舍入容差 `16·Number.EPSILON·max(|a|,|b|)`，不使用界面显示精度。

CD 解由预算等式和适用的内点条件推导为 x*=αm/px、y*=(1−α)m/py。线性比较 a/px 与 b/py：严格较大者对应角点，相等时输出包含两个端点的 `optimal_set`，表示整段预算边界，不能将一个中点称为唯一最优。零预算把该集合退化为唯一原点。互补解 x=y=m/(px+py)，是不可微拐角。

平方表示仅用于 u≥0 的确定性序数选择。表示变换不进入优化公式，也不改变同一偏好下的排序；效用表示与偏好模式/权重是不同输入。CD 效用用加权对数的指数计算以避免中间乘积溢出；不在零数量上求对数。MRS 在轴、互补拐角和 MUy=0 的分支报告未定义，不将 Infinity/NaN 输出给页面。在互补的 x>y>0 分支，MUx=0、MUy=1，因此局部 MRS=0；这是直角曲线水平部分，不能误认为拐角有唯一斜率。

## 图形与集合值需求

无差异集合输出 `Point[][]`，每个数组是一条折线。CD 的 u=0 用两条轴表示；互补用三点的真实直角折线表示，不平滑。曲线只在指定图形矩形内作显式几何裁切，不更改经济参数。正 CD 水平集用对数间距采样以保留靠轴的陡峭部分。

需求数据对每个 px 调用同一个 `solveChoice`，横轴数量、纵轴 px。线性偏好若在扫描区间内有并列价格，即使扫描数组未恰好包含该价格，也插入该价格及完整最优数量区间；图形应断开两侧分支并单独展示区间，不能将多值关系伪造成连续单值插值。

## 独立网格与验证容差

理论 oracle 使用绝对/相对 1e−8 容差。独立 CD 网格测试不调用内核效用或解析解：用 400 个 x 分段，并在每个 x 的剩余预算中独立扫描 400 个 y 分段，直接计算 x^α·y^(1−α)。该网格是有限近似，数量容差按各轴最大购买数量/400 明确给出，目标值差容差为解析效用的 1e−4；不能把这些网格容差用于解析答案或 UI 求解。另检验所有预算、偏好表示变换、零预算、线性并列集合、互补拐角、轴上 MRS、连续价格扫描与非法域。

原设计中的首期数学 oracle 无需修正。实验均为 synthetic 教学参数；这些偏好族的比较静态不能解释为所有现实商品的经验定律。

## 完整课程：ML04–ML11

后续模型位于 `app/src/models/advanced.ts`，不依赖 UI、网络或持久化。实验参数、数值表、SVG 绘点、练习答案和终课快照均调用 `runAdvancedLab`。`metrics` 保存未四舍五入的计算结果；显示三位小数仅用于阅读。

- ML04：本期 F 不可避免，停产利润 −F；q=max(0,(p−c)/d)，成本、MC、AC 与市场加总分开输出。个别企业面对的 p 与由 n 家供给及需求联立求出的市场价是两个不同反事实，改变前者不冒充市场冲击。q=0 的 AC 及无交易市场价格用 null。
- ML05：交易量被模型非负约束截断为0；无交易不报告唯一买卖成交价。CS+PS+税收+DWL 与无税总剩余对账；法定征收方仅改变说明，在本模型竞争/遵从条件下不改变结果。弹性为局部无量纲响应，不能用反需求斜率代替。
- ML06：竞争及垄断基准均条件于运营，同一 F 各扣一次，差额中抵消。数量公式不包括可避免固定成本下的进入退出。网络效应使用独立的定性情景面板，不偷改线性需求并声称求解平台均衡。
- ML07：逐行逐列枚举双方全部并列最佳回应，返回全部纯策略均衡；Pareto 改善另行标记，0个纯策略均衡不等于无混合均衡。矩阵不模拟重复博弈或承诺的时间结构。
- ML08：需求是边际愿付价，社会成本额外包括 eq；总损害为 eq²/2，纠正税取 e·qs。福利只计真实资源与损害，税收不重复增加。信息及无执行成本是模型前提，不推导现实最优税率。
- ML09：从全部现存类型参与的指定信念开始，永久剔除拒绝者；阈值相等接受，初始份额0的类型不加入。每轮信念、报价与参与均显示；这不是唯一均衡证明。认证净增益=买方价值−费用−卖方保留价值；可以拒绝认证。
- ML10：风险 √w 在零财富仍有效。跨期 log 消费和劳动 log 消费/闲暇有严格正域；无可行正域报告 null，其他面板仍计算。借款限制绑定时用 c1=y1 重新从完整预算推出 c2；劳动角点从可行域重新判断。期望效用的表示限制是正仿射，不能挪用确定性序数的任意严格递增变换。
- ML11：按比较优势决定专业化方向，tradeX 明确为 A→B 的有符号 x 净出口，反向示例为负；交易受两国现有产量约束。PPF 和受双方供给限制的 CPF 分别绘制。端点只有弱可行集利得，相同机会成本无严格比较优势；消费可行不自动代表偏好提高或自动补偿国内受损者。

高级 SVG 使用两情景绘点的联合坐标域，允许有经济意义的负值（如 MR），并提供所有绘点的替代表格。无硬编码美术曲线。参数域外输入保留错误草稿并隐藏旧结果，需要修正后重新运行；正常经济角点与非法参数是不同状态。

## 学习工具与进阶实验补充

用户后续将范围扩大到课程五项学习工具。schema3 保留历史 key，严格迁移 v1/v2；加载不覆写旧原文。复习建议用 UTC 时间戳保存，不写回原题客观尝试或生成掌握率。24 道数值检查各有 23 个轮换新参数情境，使用同一个实验内核；选择题仅重排且明确说明。多次快照保存精确输入和 modelVersion1，显示/报告重新使用内核计算；未来变更该模型版本需显式迁移，不能静默改变历史含义。快照最多40份，满额拒绝，不丢弃旧记录。

MX01 在 CD 域 0<α<1、正价格、非负收入解有限 Slutsky 与 Hicks 分解。Hicks 支出为 m(px1/px0)^α；补偿使原效用水平可达到，两种补偿的替代/收入项各自相加为总效应，有限冲击下两分解通常不同。零预算与不变价格另处理。

MX02 企业成本 F+cq+dq²/2，需求 Q=A−Bp。n 家价格接受企业的条件均衡由计划一致推出；长期连续近似的 minAC=c+√(2Fd)，q*=√(2F/d)。整数进入用“现有企业利润≥0；再进入一家后的利润≤0”，弱边界可容许相邻两个 n，并单列区间。这不是 Cournot，也不是进入调整路径。F=0、正需求下 AC 下确界不能由有限企业数实现；零需求/零固定成本可有任意闲置数，页面给规范代表0与边界说明。无交易不伪造唯一成交价格。

MX03 枚举两人各两行动的九种支持组合，以线性最佳回应不等式求概率区间；删除被其他区域包含的重复，保留连续均衡而不捏造有限计数。真内点根因机器精度舍入为0/1时明确拒绝，避免伪造纯均衡。重复PD另用独立 R,S,T,P 与 δ，限定 T>R>P>S、0≤δ<1、无限期限、完美监测和可信grim惩罚；合作条件 δ≥(T−R)/(T−P)，不声称枚举所有重复均衡。

运行时目录只引用轻量JSON，四组正文、词条与所有工具动态 import。单元测试将JSON元数据与全部typed正文/词条/模型卡逐项核验；实际生产浏览器检查首页未请求正文块。全文搜索是用户显式选择后才加载全课程，搜索不索引个人笔记。打印临时以纯文本复制控件值，展开 details，afterprint 恢复，避免 textarea 只打印可见几行。
