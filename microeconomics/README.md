# 微观经济学｜从选择到市场与制度

**courseId:** `microeconomics`  
**状态：** 课程设计完成；Web 实现待 Codex。12 模块 / 24 节核心课；首期实现 M01–M03。

## 一条主线

资源有限 → 有哪些可选方案 → 如何表达偏好 → 怎样作最优选择 → 选择如何随价格和约束变化 → 多个人与企业如何相互兼容 → 市场什么时候协调得好、什么时候需要不同制度。

形式骨架是 `选择 ∈ 可行集`、`在给定条件下比较结果`、`相互作用下形成均衡`。第一节不要求相信“人必然自私理性”；先把它当一组明确、可修改的建模假设。偏好可以包含他人福祉；无法观察到的效用不是幸福计量仪。

学完应能：从约束推导选择、从选择推导需求，解释企业成本和竞争，区分均衡/效率/公平，分析市场力量、策略互动、外部性和信息问题，并给出机制与证据分开的现实分析。

## 适合怎样学

先在图中分清“一个方案”“所有可行方案”“偏好排序”“价格约束”，再看优化公式。数学不难不等于对象清楚；遇到推导卡住时，先回看对象和假设。

重点练习这些误解：效用数值就是幸福；最优点一定相切；价格与销量一起上涨就说明需求向上；征税对象就是最终负担者；没有利润就没有企业；均衡就是公平；边际成本很低就应该永远免费。

示例使用抽象消费组合、虚构数字服务、共享资源和贸易经济体。它们不记录学习者的真实财务，不提供现实投资建议。
