# 微观经济学｜从选择到市场与制度

**courseId:** `microeconomics`  
**状态：** 12 模块 / 24 节完整中文课程、ML01–ML11 共 11 个基础实验、MX01–MX03 共 3 个进阶实验，包含逐课练习反馈、模型卡、概念词条、跨模块复习、终课作品和本地学习记录。课程正文与实验均已实现，不再以规划简介代替课程。

## 一条主线

资源有限 → 可行方案 → 偏好与选择 → 技术与成本 → 市场兼容 → 福利与分配 → 策略、制度和信息 → 时间与贸易 → 可审查的机制与证据。

课程面向没有系统经济学前置、愿意理解直觉与推导的学习者。每节保持问题、对象、图像、最小模型、预测与实验、反例、重建与迁移的七步结构。允许跳读；数学插页按需解释，不以翻页、停留时间或点击次数冒充掌握。

## 实际课程

| 模块 | 两节核心课 | 实验 |
| --- | --- | --- |
| M01–M03 | 稀缺与预算；偏好与表示；最优选择与需求 | ML01 可行域、ML02 序数表示、ML03 选择与需求 |
| M04–M06 | 技术与成本；企业与市场；弹性、税收与福利 | ML04 成本/供给/市场、ML05 税楔与福利 |
| M07–M09 | 市场力量；策略与规则；外部性、公共品与制度 | ML06 垄断/竞争、ML07 所有纯策略最佳回应、ML08 外部影响 |
| M10–M12 | 风险与信息；劳动与跨期；贸易、整体与证据 | ML09 质量与参与、ML10 风险/跨期/劳动、ML11 比较优势与贸易 |

每课四题，共 96 题：解释自评、误解选择、同内核数值、迁移自评。另有四个使用新数字和新情景的跨模块复习。自由文字采用参考解释和独立 rubric，不使用关键词评分或 LLM。

实验保留 A/B 参数、保存预测或显式跳过后运行、数值表、同尺度 SVG、模型条件、解释与独立重置。退化、无交易、并列、无纯策略均衡、无正消费对数域均明确区分，非法参数不会被静默裁剪。

终课作品提供六个可保存的报告部分，要求一个明确模型、两个反事实、一个反例、分配影响和证据边界。作品可导出文本及所选已保存的实验历史快照；完整学习记录使用 JSON 备份和恢复。没有在线提交、同伴分享或自动评审。

## 学习工具

- 错题与间隔复习：客观答错、解释仍有疑问时加入本地队列。数值题用新参数，选择题调整顺序，自由回答仍由自己对照 rubric；选择再练、吃力、能解释后安排 1 / 3 / 7→14→30→60 天复习。可提前练习，不发送外部提醒。
- 实验历史：运行后显式命名保存 A/B、预测和解释，最多 40 份；修改当前实验不会覆盖历史。恢复与删除须确认，终课作品引用两份不同反事实并附同内核结果。满额或大小超限时保留原记录，先导出再自行选择删除。
- 进阶实验：MX01 比较有限价格变动的 Slutsky/Hicks 补偿分解；MX02 比较初始短期、连续企业近似与整数进入退出条件；MX03 枚举全部 2×2 纯/混合支持（含连续集合），并单独检验无限重复囚徒困境 grim-trigger 的合作条件。
- 两个现实案例：2020 年美国卡支出与地区收入分组、常规失业保险初请/续请。提供六个已核验历史日期、图表、日期比较、原始摘录和完整来源导出，见 [REAL_CASES.md](REAL_CASES.md)。观测与 synthetic 模型明确区分，不估计政策因果或展示实时数据。
- 搜索与阅读输出：先检索目录/概念，选择全文时才加载 24 节正文；课程正文、词条和工具按需加载。可打印当前页/PDF、完整笔记与模型卡，或显式导出本节纯文本；打印会展开推导和模型卡并保留完整文本。

## 启动与验证

使用 Node 24 和 npm，从仓库根目录运行：

```sh
cd microeconomics/app
npm ci
npm run dev
```

默认端口 5173，占用时明确报错。使用 hash 深链接与相对资源 base；例如 `/#/lesson/M12-A` 可刷新，无须服务器 rewrite。全部正文、图形和应用依赖使用本地构建资源，外部参考仅由学习者主动打开。

```sh
npm run typecheck
npm test
npm run test:content
npm run build
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
E2E_PRODUCTION=1 CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e -- tests/e2e/learning-navigation.spec.ts tests/e2e/learning-extensions.spec.ts tests/e2e/learning-cases.spec.ts
```

没有系统 Chromium 时，先执行 `npx playwright install chromium`，再运行 `npm run test:e2e`。E2E 启动独立开发服务器，请先释放本任务自己的 5173 端口。实际结果和截图见 [DELIVERY.md](DELIVERY.md)。
