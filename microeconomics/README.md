# 微观经济学｜从选择到市场与制度

**courseId:** `microeconomics`  
**状态：** Phase 1 已实现并通过实际测试：M01–M03 六节中文课程、ML01–ML03 三个交互实验。完整目录为 12 模块 / 24 节；后续 18 节明确标记“已规划，未实现”。

## 一条主线

资源有限 → 有哪些可选方案 → 如何表达偏好 → 怎样作最优选择 → 选择如何随价格和约束变化 → 多个人与企业如何相互兼容 → 市场什么时候协调得好、什么时候需要不同制度。

形式骨架是 `选择 ∈ 可行集`、`在给定条件下比较结果`、`相互作用下形成均衡`。第一节不要求相信“人必然自私理性”；先把它当一组明确、可修改的建模假设。偏好可以包含他人福祉；无法观察到的效用不是幸福计量仪。

完整课程的规划目标：从约束推导选择、从选择推导需求，解释企业成本和竞争，区分均衡/效率/公平，分析市场力量、策略互动、外部性和信息问题，并给出机制与证据分开的现实分析。当前 Phase 1 实现的是约束、偏好、最优选择与需求。

## 适合怎样学

先在图中分清“一个方案”“所有可行方案”“偏好排序”“价格约束”，再看优化公式。数学不难不等于对象清楚；遇到推导卡住时，先回看对象和假设。

重点练习这些误解：效用数值就是幸福；最优点一定相切；价格与销量一起上涨就说明需求向上；征税对象就是最终负担者；没有利润就没有企业；均衡就是公平；边际成本很低就应该永远免费。

示例使用抽象消费组合、虚构数字服务、共享资源和贸易经济体。它们不记录学习者的真实财务，不提供现实投资建议。

## 启动与验证

使用 Node 24 与 npm；从仓库根目录运行：

```sh
cd microeconomics/app
npm ci
npm run dev
```

默认地址 `http://localhost:5173/`；端口占用时明确报错。课程使用 hash 深链接，例如 `/#/lesson/M01-A`，构建资源 base 为 `./`，可从服务器子路径运行。所有课程、SVG 图形与字体回退均为本地资源。

```sh
npm run typecheck
npm test
npm run test:content
npm run build
npm run test:e2e
```

浏览器 E2E 使用 Playwright。第一次可执行 `npx playwright install chromium`；已有系统 Chromium 时用 `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`。本次使用系统 Chromium 实际运行，完整结果、截图、模型边界与实际 commit 见 [DELIVERY.md](DELIVERY.md)，数学实现与网格容差见 [IMPLEMENTATION_NOTES.md](IMPLEMENTATION_NOTES.md)。
