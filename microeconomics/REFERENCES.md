# 微观参考资料与阅读路线

核验日期：**2026-10-03**。以下官方网页已核验可访问；核验的是课程或目录入口，不意味着逐一审校全部外链、讲义、视频或历史数字。本站教学顺序、文案、例题和合成参数为原创设计，不代表原作者背书。

## MIC-MIT｜MIT OpenCourseWare，14.01SC Principles of Microeconomics，Fall 2011

入口：https://ocw.mit.edu/courses/14-01sc-principles-of-microeconomics-fall-2011/

用途：作为传统微观理论的结构性校验与进阶练习入口。官方目录覆盖供需、消费者理论、生产者理论、福利、垄断与寡头、要素、贸易、不确定性及公平。选择对应主题查阅，不要求从第一讲重看全部视频。

映射：M01–M03 → Consumer Theory；M04–M06 → Producer Theory / Supply and Demand / Welfare；M07–M08 → Monopoly and Oligopoly；M10–M12 → Uncertainty / Factor Markets / Capital / International Trade / Equity and Efficiency。

页面版本是 2011 年课程。涉及当时政策、数据和制度的材料只作为历史资料，不当作当前事实。题目只链接，不复制题库与答案。

## MIC-CORE｜CORE Econ，The Economy 2.0: Microeconomics

目录：https://books.core-econ.org/the-economy/microeconomics/0-3-contents.html

用途：对照制度、分配、技术、策略互动和现实问题，避免把微观学成只有“供需交点”的工具箱。

最小映射：M01–M03 → Units 2–3；M04 → Units 2/7；M05–M06 → Units 8/10；M07 → Unit 7；M08 → Units 4–5；M09 → Units 4/10；M10–M11 → Units 3/6/9；M12 → Units 2/5/10。

推荐读法：先完成本课模型卡，遇到未闭合的问题再读对应 section；涉及实证结论继续追踪该 section 的原始研究与时期。CORE 与 MIT 的组织方式和模型强调点不同，差异可用于比较，不应消除成一个无条件结论。

## 引用与素材规则

课程内容的 `references` 保存上述 ID 及具体 unit/topic；需要支撑详细经验事实时追加可追溯的原始研究，而不是只挂一本书的首页。每条新增来源记录 title、author/organization、URL、edition/date、checkedAt、支持的命题与 license note。

外部材料用于阅读与核验；不要下载整本书、复制原图或批量搬运练习。免费可读不自动代表可再发布。引用少量原文或复用素材前核验当时许可、署名、修改标注及其他条款。

应用不在运行时请求这些网站；参考链接由学习者主动打开。默认实验不使用真实市场数据，也不连接付费 API。
